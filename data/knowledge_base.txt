### Machine Learning Fundamentals
Machine learning is categorized into three main types: Supervised Learning, Unsupervised Learning, and Reinforcement Learning. Supervised learning uses labeled data. Unsupervised learning finds patterns in unlabeled data. Reinforcement learning involves an agent learning through trial and error.
Overfitting occurs when a model learns the training data too well, including its noise, leading to poor generalization on new data. Regularization (like L1 or L2) prevents overfitting by adding a penalty for large weights.
The bias-variance tradeoff describes the conflict between a model's simplicity (high bias) and its sensitivity to data fluctuations (high variance). Cross-validation is a technique to evaluate model performance by splitting data into multiple folds.

### Deep Learning and Neural Networks
Backpropagation is the algorithm used to train neural networks by calculating gradients and updating weights. Activation functions like ReLU, Sigmoid, and Tanh introduce non-linearity.
Convolutional Neural Networks (CNNs) are primarily used for image processing and computer vision. Pooling layers in CNNs reduce spatial dimensions and help achieve translation invariance.
Long Short-Term Memory (LSTM) networks address the vanishing gradient problem in RNNs using a gating mechanism (forget, input, and output gates).

### Natural Language Processing (NLP) and Transformers
Word embeddings like Word2Vec and GloVe represent words as dense vectors in a continuous space, capturing semantic relationships. Transfer learning in NLP involves pre-training models on large corpora and fine-tuning them on specific tasks.
The Transformer architecture, introduced in "Attention is All You Need," relies on the self-attention mechanism to process sequences in parallel. BERT (Bidirectional Encoder Representations from Transformers) is pre-trained for language understanding using masked language modeling. GPT (Generative Pre-trained Transformer) is a decoder-only model trained for next-token prediction.
Self-attention allows the model to weigh the importance of different words in a sentence relative to each other. Instruction tuning and RLHF (Reinforcement Learning from Human Feedback) are used to align LLMs with human instructions and preferences.
Chain-of-thought prompting encourages the model to explain its reasoning step-by-step. GPT-4 has a significantly larger context length (up to 128k tokens) compared to earlier models.

### Retrieval-Augmented Generation (RAG)
RAG (Retrieval-Augmented Generation) combines LLMs with external knowledge retrieval. The main components are a retriever, a knowledge base, and a generator (LLM).
Dense retrieval uses embeddings to find relevant documents semantically. Chunking strategy is crucial because it determines the granularity of retrieved information; smaller chunks (e.g., 500 tokens) often provide better precision.
Advanced RAG techniques include query expansion, reranking, and multi-stage retrieval.

### Vector Databases and Search
Vector databases store and index embeddings for efficient similarity search. FAISS (Facebook AI Similarity Search) is a library for efficient similarity search and clustering of dense vectors.
HNSW (Hierarchical Navigable Small World) is a popular graph-based indexing algorithm for approximate nearest neighbors. Hybrid search combines semantic (vector) search with keyword (BM25) matching.

### LangChain and LLM Tooling
LangChain is a framework for building applications with LLMs. LangChain Expression Language (LCEL) is a declarative way to compose chains using the pipe operator (|). LangGraph enables building cyclic and stateful multi-agent systems.
LangChain supports various memory types (Buffer, Summary, Entity) and retrievers (VectorStore, ParentDocument, Ensemble).

### LangSmith and Observability
LangSmith is a platform for debugging, testing, and monitoring LLM applications. It captures traces including inputs, outputs, latency, and token usage.
The LangSmith Prompt Hub is a central repository for versioning and sharing prompt templates. LangSmith datasets are used for benchmarking and regression testing.

### Evaluation and Safety
RAGAS is a framework for automated evaluation of RAG pipelines. Key metrics include Faithfulness (is the answer derived from context?), Answer Relevancy, Context Recall (was the ground truth retrieved?), and Context Precision.
Guardrails AI provides validators for LLM outputs, such as detecting PII (Personally Identifiable Information) or ensuring structured output (JSON).
Constitutional AI involves training models to follow a set of safety and ethical principles. Common AI safety concerns include hallucinations, bias, and prompt injection.
PII detection is important to prevent sensitive data (emails, phones, SSNs) from being leaked in LLM responses. Structured output validation ensures that LLMs return data in a predictable format like JSON for programmatic use.
